Detailed Description

后端 DSO 加载器：从可信目录 dlopen 后端并完成 ABI 握手。

契约：后端 DSO 必须导出 const rkvc_backend *rkvc_backend_query(void)， 返回的 rkvc_backend.abi_version 必须等于核心 RKVC_ABI_VERSION，否则淘汰。 单个候选失败只淘汰该候选（计数 + 首条诊断），不影响上下文创建；候选 顺序 = 内建后端 → 按路径排序的 DSO（确定性）。句柄随 context 关闭。
