Detailed Description

模型注册表：.rkmodel 候选的只读查询（公共 ABI）。

注册表在 context 创建时扫描模型目录中的 .rkmodel 容器，只读取有界 头部并完成格式/兼容性过滤；载荷按请求装载。目录名仅用于组织文件， 不参与正确性判断。
