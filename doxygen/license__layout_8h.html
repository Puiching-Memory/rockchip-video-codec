Detailed Description

授权 blob 线格式常量（lib/license.c 与 tools/rkvc_lic.c 的单一来源）。

签发端（rkvc_lic）与校验端（librkvc）必须字节级一致，故共享此头文件， 避免魔法数 / 区域长度在两处手抄后漂移，导致校验静默失败。
