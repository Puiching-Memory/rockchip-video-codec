Detailed Description

诊断单元：一次失败/淘汰的可解释记录。

图规划器与后端在“为何选中/淘汰某个候选”时逐条追加诊断， 形成可检查的链（类似错误堆栈），供 CLI 按文本或 JSON 输出。
