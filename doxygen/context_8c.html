Detailed Description

rkvc_context：设备探测、后端注册表与图规划器。

探测失败只淘汰候选，不使上下文创建失败；设备能力用 rkvc_probe_device 查询。候选顺序由注册顺序 + 工厂顺序决定（确定性），不依赖 readdir()。
