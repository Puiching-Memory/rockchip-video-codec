rkvc_err rkvc_session_run_file ( rkvc_session *  session)

文件 / 采集模板：阻塞跑完整条管线。

  • FILE_* / AV1_STORAGE：处理 input_path/output_path
  • LIVE_CAPTURE：从 capture_device 拉帧编码到 output_path

内部 start → 处理 → stop。纯端口流式（手动 push/pull）请勿使用。

Returns
RKVC_OK 或 I/O / 编解码错误。
