Detailed Description

1机1码授权（Ed25519 非对称签名）。

机器码由本机硬件指纹（设备树序列号 / OTP / MAC）经 SHA-256 派生； 注册码由持有私钥的发码端对「机器码 + 产品」做 Ed25519 签名。 库内嵌公钥本地校验，无需联网；私钥泄露前无法伪造注册码。

授权一经签发永久有效（无有效期字段，不做到期校验）。 仅当 CMake 选项 RKVC_ENABLE_LICENSE=ON 时编译本模块。
