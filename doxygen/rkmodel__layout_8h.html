Detailed Description

.rkmodel v1 容器线格式（读写两侧单一来源）。

布局（全部小端序）： 固定头（64 字节） TLV 头区（header_len 字节，有界 <= RKMODEL_MAX_HEADER） 载荷表（payload_count x 24 字节） 载荷数据（按表项 offset/length 寻址）

未知 TLV tag 必须可跳过；整数端序固定；所有长度读前检查上界。
