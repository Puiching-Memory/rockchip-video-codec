Detailed Description

库上下文：持有设备探测、后端/模型注册表、搜索路径与线程设置。

所有全局状态迁入 rkvc_context；只允许日志后端与不可变进程信息 进程级共享。上下文负责定义可信后端与模型搜索路径。

创建上下文并探测设备、装载后端与模型注册表。
