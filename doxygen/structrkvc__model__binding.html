Detailed Description

交付给节点的模型绑定：容器摘要 + 已校验的载荷字节。 info 与各载荷指针均为核心/上下文持有的只读存储；节点不得释放。

兼容字段 payload/payload_size 指向缺省载荷（RKNN；容器未携带时 为首个载荷）。payloads/payload_count 是同一容器全部载荷的视图， 供需要多载荷（如 MLVC 的 RKNN + 双 PMF 熵表）的节点按 kind 取用； 载荷视图按容器表序排列，节点用 RKMODEL_PAYLOAD_* 匹配 kind。

前置声明：节点虚表中的 bind_model 回调以此指针类型为参。 完整定义见下方 rkvc_model_binding。
