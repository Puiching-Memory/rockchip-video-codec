Detailed Description

SVT-AV1 软件编码节点（经 FFmpeg libsvtav1）。

输入帧先落到 host AVFrame；libsvtav1 仅接受 YUV420P/YUV420P10， NV12 等格式经 swscale 转换后再送入编码器。
